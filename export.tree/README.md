# ds001734 - FitLins derivatives

This is a derivatives dataset resulting from running FitLins on [ds001734](https://openneuro.org/datasets/ds001734).

## Methods

FitLins documentation can be found at https://fitlins.readthedocs.io/. The code for the workflow used to run FitLins can be found at https://github.com/demidenm/openneuro_glmfitlins.

Users should note the following:
  1) Design matrices should be reviewed closely. See `code/openneuro_glmfitlins/statsmodel_specs/`.
  2) Motion parameters should be reviewed, as subjects were not excluded for motion.
